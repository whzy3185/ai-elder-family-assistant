# 演示指南

版本1.1.0；主要尺寸390×844。启动后，默认 `/` 是张阿姨产品，`/family` 是小梅产品，`/review` 是产品之外的评审辅助。语音、消息、邀请、提醒、整理及失败为预置状态，不录音，也不真实联系家属。

## 连续主流程

先在辅助工具恢复初始状态。张阿姨“家人”→邀请小梅；切换小梅→家人→向妈妈申请；切回张阿姨→家人→核对小梅→同意并确认。也可以用两个产品地址依次扮演双方设备。

张阿姨“事情”→记一件事→填写README原话或用语音按钮填入它→帮我整理。检查8:00，点击改时间→上午9:00，看到8:30提醒→确认记好。详情里请小梅陪你去→查看共享→发给小梅。

小梅查看消息→打开请求→我可以陪你→确认。返回张阿姨→查看这件事→看看小梅的答复。小梅可以陪同；公交卡年审仍需张阿姨在详情“这件事办完了”后亲自确认。

## 分支入口

| 情况 | 辅助快捷入口 | 产品内继续操作与结果 |
|---|---|---|
| 首次关系 | 首次使用 | 双方申请/确认；老人拒绝仍可自己记事 |
| 改时间 | 时间需要修改 | 8点改9点，提醒同步为8:30 |
| 只提醒自己 | 正常流程 | 只提醒我自己；小梅消息里没有事务 |
| 信息不足 | 信息没听全 | 自己填时间/地点，再核对并保存 |
| 整理失败 | 暂时没整理好 | 原话保留；手动填写或再试一次 |
| 发送失败 | 消息没有发出去 | 重新发送；小梅之前无请求，重试后只有一条 |
| 未回应 | 小梅还没回复 | 再等一等，或撤回陪同；个人提醒保留 |
| 陪同答复 | 小梅可以陪同 / 这次不能陪同 | 详情查看答复；个人事务不自动完成或取消 |
| 建议改期 | 小梅建议改时间 | 由老人同意或保留原时间；同意后仍需重新查看共享、确认发送 |
| 撤回 | 正常流程先发送，或已撤回陪同 | 撤回确认后提醒保留；小梅不能再回应 |
| 取消事情 | 正常流程，或事情已取消 | 取消需确认；提醒停止，原请求不可回应 |
| 接受后修改 | 小梅可以陪同 | 修改时间→继续→确认下午2点；旧答复不沿用，再分享后等新答复 |
| 提醒/完成 | 提醒时间到了 | 查看事情；现实办完才确认完成 |
| 结束协作 | 已建立关系后的家人页 | 结束需确认；旧请求不可回应，个人事情保留 |

## 全部画面、时钟与恢复

辅助工具“查看全部画面”覆盖65项。界面不显示内部编号，材料页面索引按编号对应自然中文标题；发送/整理中的辅助快照可在“演示时间”区域继续，正常业务自动推进。

初始时间10月6日20:00，“明天”固定10月7日；09:00/08:30提醒，修改为14:00/13:30提醒。辅助工具可查看提醒时间到了和未回复；这些入口不在老人产品内。

恢复初始状态需要确认，清空当前浏览器原型数据并恢复固定时间。刷新保留数据；发送中刷新进入“没有发给小梅”，允许重试。状态只在同一浏览器持久化；不支持跨设备或跨标签页实时协同。
