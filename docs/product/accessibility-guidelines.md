# 适老交互规范

版本：`ACCESSIBILITY_GUIDELINES_VERSION=1.0.0`

冻结日期：2026-10-06（Asia/Shanghai）

本规范是后续设计、Web、静态导出和视觉审计的 P0 验收基线。与早期研究建议冲突时，以本冻结版本为准。

## 1. 主要环境

| 项目 | 冻结值 |
|---|---|
| 主要 viewport | 390 × 844 CSS px |
| 方向 | 竖屏 |
| 演示方式 | 桌面浏览器中的响应式窄栏或手机框 |
| 老人端输入 | 模拟语音 + 完整文字替代 |
| 手势要求 | 点击和键盘即可完成全部 P0 |
| 缩放要求 | 浏览器 200% 放大时主流程不丢失功能 |

## 2. 字体和信息层级

| 用途 | 建议字号 | 最小行高 | 规则 |
|---|---:|---:|---|
| 页面标题 | 28 px | 1.3 | 每页一个，说明当前任务 |
| 关键结果/时间 | 24—28 px | 1.35 | 不用全大写或过细字重 |
| 老人端正文 | 20 px | 1.6 | P0 默认值，不依赖设置开关 |
| 按钮文字 | 20 px | 1.3 | 动词优先，避免术语 |
| 辅助说明 | 18 px | 1.5 | 不承载唯一关键信息 |
| 家属端正文 | 18 px | 1.5 | 仍保持移动端可读性 |

- 不用低对比小字解释权限或危险后果；
- 一行尽量只表达一个判断；
- 时间同时显示相对与绝对值，如“明天 9:00（10 月 7 日）”；
- 禁止用占位符代替字段标签；输入后标签仍可见。

## 3. 对比与状态表达

- 普通文字与背景对比度至少 4.5:1；大号粗体文字至少 3:1；
- 关键正文和主要操作优先达到 7:1；
- 焦点边框、输入边界和图形控件与相邻颜色至少形成清楚差异；
- 成功、等待、警告、失败都必须同时使用文字和图标/形状，不能只靠绿、黄、红；
- 禁用状态仍须可读，并写明为什么不可操作；
- 背景装饰不能穿过正文或降低可读性。

## 4. 触控与操作

| 控件 | 冻结规则 |
|---|---|
| 主按钮 | 高度至少 56 px，尽量满行，页面只突出一个 |
| 次按钮 | 触控区域至少 48 × 48 px |
| 图标按钮 | 不作为关键动作唯一入口；带可见文字或可访问名称 |
| 控件间距 | 独立触控区之间至少 12 px，危险动作与主操作分组 |
| 表单字段 | 整行可点击，错误紧邻字段显示 |
| 返回 | 始终可见；返回不清空输入和修正结果 |

全部 P0 不得依赖：

- hover 才出现的操作；
- 长按；
- 双击；
- 精细拖拽；
- 复杂滑动或隐藏手势；
- 只有触屏才能完成的动作。

键盘焦点顺序必须与视觉顺序一致；焦点样式始终可见；弹窗打开后焦点进入弹窗，关闭后回到触发控件。

## 5. 页面节奏

- 一个画面只突出一个主操作；
- 主要操作放在阅读顺序末端并保持位置稳定；
- 主流程每一步回答“发生了什么、现在是什么、接下来能做什么”；
- 不用一屏堆叠创建、共享和完成三个决定；
- 保存个人事务与发送家庭请求必须分屏；
- 重要结果使用可停留的页面或页内状态，不能只显示 toast；
- 加载超过瞬时反馈时显示明确处理中状态，并阻止重复提交；
- 空状态、失败状态和终态都提供下一步。

## 6. 输入、纠错和替代方式

- 语音入口旁必须有“手动填写”；
- 模拟语音结束后显示原始文字；
- 识别结果按字段显示，不把整段回复藏在聊天气泡里；
- “改时间”等单字段操作必须直接可见；
- 错误后保留原输入和已经确认的其他字段；
- AI 失败时手动表单能够独立完成流程；
- 输入错误用文字说明位置和修复方法，不只加红色边框；
- 不用倒计时迫使老人快速操作。

## 7. 反馈和危险操作

| 动作 | 反馈要求 |
|---|---|
| 保存事务 | 明确写“这件事已记好”和 08:30 提醒 |
| 发送请求 | 发送中、发送成功、等待回应、发送失败分开呈现 |
| 家属回应 | 说明小梅的选择；不得写事务已完成 |
| 撤回请求 | 二次确认并写明事务与提醒保留 |
| 取消事务 | 二次确认并写明提醒和请求都会终止 |
| 修改已共享事务 | 确认旧请求会失效，再决定是否重新分享 |
| 完成事务 | 二次确认“现实事情已经办完”，不能由家属代操作 |

危险操作的确认按钮必须写明对象，例如“取消这件事”，不得只写“确定”。取消确认弹窗的安全返回动作清晰可见。

## 8. 成人化与尊重

- 把张阿姨视为有自主决定能力的成年人；
- 不使用幼儿化插画、拟声词或哄劝语气；
- 不因年龄默认开启监控、定位或家属托管；
- 不用“很简单”“你又错了”“让孩子帮你弄”等贬低文案；
- 不把操作慢解释为理解能力不足；
- 小梅是受邀协助者，不称“管理人”或“监护人”。

## 9. P1 显示设置

`EL-SET-01` 可在全部 P0 完成后提供“标准 / 大字”和高对比切换。P1 不得成为 P0 可读性的补救：默认模式本身必须满足上述字号、触控和对比要求。未实现时不显示入口。

## 10. 页面级验收清单

每个页面在进入 阶段 14 前至少检查：

- [ ] 390 × 844 下无横向滚动，主要按钮可发现；
- [ ] 老人端正文约 20 px，主按钮不小于 56 px；
- [ ] 关键状态不只靠颜色、不只靠 toast；
- [ ] 不使用 hover、长按或复杂滑动；
- [ ] 语音页面有文字替代；
- [ ] 返回后内容仍在；
- [ ] 危险动作有后果说明与二次确认；
- [ ] 一个画面只有一个突出主操作；
- [ ] 200% 放大后可阅读、可滚动、可完成；
- [ ] 键盘焦点可见且顺序合理；
- [ ] 文案符合 `content-guidelines.md`；
- [ ] 页面有稳定 `data-screen-id` 并与页面矩阵一致。
