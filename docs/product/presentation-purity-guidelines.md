# 产品界面呈现规范

机器规则：`config/presentation-purity.json`。产品扫描范围为默认`/`、`/family`及Review中的`.product-surface`用户可见文字、按钮、标签、placeholder、可访问名称；内部data属性不属于可见文案。大小写不敏感，技术词按词边界，中文按字串匹配。

产品禁止列表包含Prompt/Prototype/Demo/Scenario/Fixture/Snapshot/Reset、业务枚举、字段/协议术语、test/debug，以及演示、模拟、预置、测试、评审、控制台、快照、加载场景、本地服务等。产品没有身份切换、人工失败触发、时间推进和版本号。隐藏DOM仍需检查，不能用CSS掩盖混合结构。

Review允许“评审辅助、演示时间、快速查看、切换身份、恢复初始状态”；只说明一次“用于快速查看不同演示情况，不属于正式产品功能。语音、消息和提醒为预置演示状态。”内部场景ID和技术协议词仍禁止可见。

产品只说用户要知道的结果和下一步。未知是否正确时说“我这样记，对吗？”，不自称识别错误；失败保留输入，支持重试或手动；时间修改后说“时间改过了，需要再问一次小梅”。不以删除异常页面减少命中。模型枚举保留，仅限制渲染。
