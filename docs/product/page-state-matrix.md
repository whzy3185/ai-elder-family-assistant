## 1. 编号规则

- `EL-*`：老人端；
- `FM-*`：家属端；
- `DM-*`：演示控制层；
- `REL`：关系；`TASK`：事务；`SHARE/REQ`：协作请求；`EX`：异常或终止状态；
- `A/B` 后缀表示同一页面族中必须可独立定位的确认与结果状态。

编号自本版本起冻结。后续可以复用布局组件，但不得删除状态 ID 或让其无法单独进入和截图。
