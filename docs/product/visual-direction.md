# 视觉方向：一本家里常用的记事本

张阿姨要记清一件外出事务，小梅需要快速判断能否陪同。界面用纸张、日期页签、清晰时间和自然家庭称谓组织信息，像日常记事本，温和但不幼儿化。既有Huawei/Apple文字记录只支持可读与字段检查方向，两款产品本人体验已确认，按原题体验要求PASS，不把新视觉称为用户实测偏好。

正常文字至少4.5:1，大号粗体至少3:1；按钮主56px、次48px，缩放可重排。产品主操作松绿，次操作文字/细边界，危险动作在后，不让全部按钮同等抢眼。

禁止紫蓝AI渐变、neon、glassmorphism、渐变文字、医学红十字、萌宠、每页状态pill、卡片套卡片及全卡片相同阴影。输入、确认、结果、详情须有不同信息结构。
