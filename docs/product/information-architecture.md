# 信息架构

版本1.1.0。/为张阿姨真实产品，/family为小梅真实产品，/review为产品之外的辅助工具。URL刷新先确定身份，再恢复当前业务状态；具体画面由共享Store及事务/请求状态定位。

张阿姨导航：事情、家人。事情→输入或手动填写→核对→改时间→确认保存→详情→是否陪同→共享预览→发送→答复。详情另有修改、完成、取消；协作等待可撤回。家人→邀请小梅→小梅申请→老人核对→同意确认或拒绝→关系详情/权限→结束确认。阅读方式从首页进入。

小梅导航：消息、家人。消息→请求详情→接受/拒绝/建议确认→结果；妈妈取消、撤回或改时间时只能查看相应结果。家人→申请→等待妈妈确认→关系详情；结束需确认。

辅助工具与手机画布视觉和DOM隔离。身份切换、快捷情况、固定时间和恢复不进入产品信息架构。13场景与65画面入口均为自然中文，内部编号不显示；静态材料使用稳定编号定位。

关系同意不自动分享事务；个人事务先保存，每次共享由老人另行确认。只共享事项、日期、时间、地点、希望陪同。家属不能修改、取消或完成个人事务。请求绑定当前版本，旧答复不可沿用。

页面清单见page-state-matrix.md；四类以上结构见page-archetypes.md。所有可见导航均有完整画面。不提供聊天、监控、健康、支付或历史中心。
