# 实现方案与综合成本

## 1. 方案结论

考核版本采用“静态响应式 Web + 确定性状态机 + 本地模拟服务 + Docker/Nginx”。这能覆盖全部页面和状态，同时避免后端、密钥、外部消息和 AI 服务成为交付风险。

## 2. 方案比较

| 方案 | 48 小时可行性 | 状态演示 | 安全暴露面 | 后续扩展 | 结论 |
|---|---:|---:|---:|---:|---|
| 静态多页面 HTML | 高 | 中 | 低 | 低 | 可用但状态一致性维护困难 |
| React/Vue SPA + 本地状态机 | 高 | 高 | 低 | 高 | **推荐** |
| SPA + 真实 BFF/数据库 | 中低 | 高 | 中高 | 高 | 超出考核必要范围 |
| 原生 iOS/Android | 低 | 高 | 中 | 高 | 构建和分发成本过高 |
| 设计工具点击原型 | 高 | 中 | 低 | 低 | 可作为静态图补充，不能替代源码与 Docker |

## 3. 推荐技术栈

- TypeScript；
- React + Vite（或同等轻量 SPA）；
- 明确 reducer/有限状态机；
- CSS variables 管理字号、颜色和间距；
- Vitest + Testing Library；
- Playwright 走查关键路径；
- Nginx 静态服务；
- Docker Compose 单服务启动。

技术栈不是评分重点，因此避免引入数据库、微服务、消息队列和真实 LLM。

## 4. 模拟实现方法

### AI 理解

预置 3 组输入与解析结果：

1. 正常解析；
2. 时间识别错误，要求用户修改；
3. 无法理解，回退到手动填写。

用统一 `AiUnderstandingAdapter` 返回固定 fixture，使未来真实 API 可以替换适配器，而页面和状态机不变。

### 家庭协作

角色切换放在标有“演示工具”的外层控制栏中。老人端和家属端读取同一份本地事件状态，所有动作通过 domain action 更新，不直接修改页面变量。

### 消息状态

提供预置开关模拟：发送中、送达、已查看、接受、拒绝、建议改期、未回应和发送失败。演示说明写明进入方法。

## 5. 48 小时成本预算

以下为规划估算，不是实际投入：

| 工作 | 预计人时 | 说明 |
|---|---:|---|
| 调研、范围与产品规则 | 6—8 | 含两个本人体验记录的整理 |
| 页面/状态清单与流程 | 3—4 | 先于视觉设计 |
| 视觉与组件基线 | 4—5 | 老人端与家属端共用设计系统 |
| Web 原型开发 | 10—14 | 主流程和关键异常 |
| 静态原型导出与文档 | 4—6 | 与 Web 同版本 |
| Docker、测试与走查 | 4—5 | 含修复缓冲 |
| 合计 | 31—42 | 需严格冻结范围 |

## 7. 真实试点的月度成本模型

以下为决策量级估算，必须在确定供应商、并发、数据驻留和 SLA 后重新报价：

| 成本项 | 小规模试点（约 100 个家庭） | 主要驱动因素 |
|---|---:|---|
| 云主机、数据库、存储和监控 | 500—2,000 元/月 | 高可用、日志保留、地区 |
| AI 理解 | 200—2,000 元/月 | 交互次数、上下文、模型单价 |
| 短信/语音/推送 | 100—2,000 元/月 | 渠道、模板、重试、通话时长 |
| 安全与合规工具 | 0—3,000 元/月 | 商业扫描、审计和密钥管理 |
| 运营与客服 | 通常高于云成本 | 培训、绑定、故障和投诉处理 |

**[分析]** 真实产品最大的综合成本通常不是模型 token，而是双端获客、首次配置、线下教育、异常处置、客服和合规。

## 8. 降本策略

- AI 只处理首次结构化，不用于每次页面文案生成；
- 规则可处理的状态不调用大模型；
- 消息渠道适配，先用低成本 App 内通知；
- 老人与家属共用组件库和领域模型；
- 首次关系建立由家庭或社区协助，减少远程客服；
- 核心业务不绑定单一硬件或 AI 供应商；
- 在验证复用率前不建设重后台和多城市运营体系。
