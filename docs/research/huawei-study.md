## 2. 体验任务

现有文字材料围绕两个与“安心记事”直接相关的任务梳理，本轮只补充官方资料核验。

### 任务一：查看适老显示方式

目标是确认华为如何降低老年用户阅读和操作负担，重点观察：

- 字体和图标是否可以放大；
- 是否只有一个固定“老人模式”；
- 页面布局是否可以进一步简化。

### 任务二：建立一次家庭守护关系

目标是确认：

- 老人和家属谁发起；
- 家属扫码后是否直接获得权限；
- 老人是否需要再次确认；
- 建立关系后家属能够获得哪些长期能力。

## 3. 操作过程与结果

### 3.1 进入关怀模式

现有文字材料结合当前官方说明整理的路径为：

**设置 → 关怀和无障碍 → 关怀模式**

进入后可以看到与显示放大、简易布局相关的设置。

### 记录与官方资料结论

关怀模式不是单纯把所有内容固定放大，而是允许用户进一步调整显示方式。

华为官方说明：

- 可一键放大字体和桌面应用图标；
- 放大显示支持多档位调节；
- 可根据个人习惯选择合适的显示大小；
- 支持桌面简易布局。[华为：关爱长辈](https://consumer.huawei.com/cn/support/content/zh-cn16094108/)

### 对本项目的直接启发

老年用户不能被假设为拥有完全相同的视觉能力。

因此“安心记事”没有设计一套极端简化、不可调节的“老人专用界面”，而是：

- 默认字号已经偏大；
- 主操作按钮扩大；
- 提供大字模式；
- 提供高对比模式；
- 减少同时出现的次要操作。

## 4. 远程守护关系建立流程（官方资料核验）

### 4.1 长辈端显示二维码

官方流程为：

**设置 → 健康使用设备 → 被家人守护 → 打开二维码**

此时只是提供建立关系的入口，家属尚未完成绑定。[华为：远程守护长辈](https://consumer.huawei.com/cn/support/content/zh-cn16073229/)

### 4.2 家属端扫码

家属端进入：

**设置 → 健康使用设备 → 守护家人 → 去守护 → 扫码添加**

使用家属设备扫描长辈端二维码。[华为：远程守护长辈](https://consumer.huawei.com/cn/support/content/zh-cn16073229/)

### 4.3 家属发送申请

扫码以后并不是直接完成绑定。

家属仍需要选择长辈并点击：

**发送申请**

### 4.4 长辈确认

长辈设备收到通知后，需要主动点击：

**同意**

随后按照界面提示完成绑定。[华为：远程守护长辈](https://consumer.huawei.com/cn/support/content/zh-cn16073229/)

### 记录与官方资料结论

这一关系并不是由家属单方面建立。

官方说明呈现双边确认结构：

**长辈提供二维码 → 家属扫码 → 家属申请 → 长辈同意 → 建立关系**

这对本项目的关系模型影响很大。

---

## 5. 建立关系后的权限说明（官方资料）

华为远程守护是一种持续性的家庭守护关系。

官方说明明确写明，绑定完成以后，家属可以进入守护家人页面并随时查看已经绑定长辈所在的位置。[华为：远程守护长辈](https://consumer.huawei.com/cn/support/content/zh-cn16073229/)

因此它解决的问题与“安心记事”并不完全相同。

华为远程守护更接近：

> 长期、持续的家庭安全和设备守护关系。

“安心记事”解决的是：

> 老人有一件具体的日常事务，在自己需要的时候询问家属能否提供一次帮助。

## 6. 主要分析与设计推演

### 观察一：老年用户不应被设计成同一种固定能力水平

关怀模式支持不同显示档位，本身说明老年用户之间仍存在明显差异。

### 对安心记事的影响

本次目标用户切片限定为：

- 有自主决策能力；
- 有基础智能手机操作能力；
- 但不喜欢复杂操作。

72 岁张阿姨只作为该用户切片的固定 Persona。

---

### 观察二：涉及家庭权限的关系需要双方确认

远程守护没有采用“家属一扫码就拥有权限”的设计。

### 对安心记事的影响

关系建立过程设计为：

**张阿姨邀请 → 小梅申请 → 张阿姨核对身份 → 张阿姨确认**

而不是：

> 小梅加入后立即获得老人信息。

---

### 观察三：建立家庭关系不应等同于自动开放全部信息

华为的长期守护关系能够持续查看位置，因此其授权范围明显高于一次事务协作。

### 对安心记事的影响

本项目把：

**家庭关系**

与

**具体事务共享**

拆成两层。

即使已经与小梅建立关系，小梅也不会自动看到：

- 张阿姨的其他事务；
- 提醒时间；
- 原始输入；
- 历史；
- 位置。

---

### 观察四：家庭协作必须可终止

长期关系如果只能建立、不能退出，会造成持续权限风险。

### 对安心记事的影响

老人和家属均有明确的结束协作流程；结束后：

- 新的家庭请求停止；
- 当前无效请求不能继续回应；
- 老人自己的事务和提醒仍然保留。

## 8. 对产品设计的影响汇总

| 华为体验与官方核验结果 | 安心记事设计 |
|---|---|
| 显示大小可调节 | 默认适老基础上提供大字模式 |
| 关怀模式降低界面复杂度 | 减少同时出现的主要操作 |
| 家属扫码后仍需申请 | 家属不能单方面建立关系 |
| 长辈必须确认 | 老人保留最终授权权 |
| 长期守护可查看位置 | 一次事务协作不开放位置 |
| 守护是一种持续关系 | 关系授权与单次事务分享分开 |
| 关系可管理和结束 | 家庭协作支持结束，个人事务不受影响 |

---

## 9. 结论

华为体验对“安心记事”最重要的启发有两点：

第一，适老设计不是把“老人”看成统一能力水平，而是提供更清晰、更易操作且具有一定可调节性的界面。

第二，家庭关系涉及持续权限时必须有明确的双方确认。

因此本项目采用：

> **老人主导关系确认 + 每件事务再次单独决定是否共享**

而没有采用持续位置或完整生活信息开放的守护模式。
